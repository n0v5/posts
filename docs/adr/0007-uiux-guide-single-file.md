# UI/UX 指南沿用单文件独立页面

《从 Flutter 出发：UI/UX 与前端界面通用入门》需要两幕结构、60 个章节、12 个本地实验室、整页目录/搜索与可离线下载；Astro 内容集合与文章布局无法同时满足这些约束。因此决定与 HTML5 大全、Dart/Rust 迁移指南一致，把页面做成 `src/pages/uiux/index.html` 的单文件自包含 HTML（内联 CSS/JS、零外部资源），不作为内容集合文章，只通过顶栏、首页 2×2 专题网格与 `.llms.txt` 接入。备选方案是 MDX 长文、Astro 布局专题页或多页系列，它们要么缺少整页导航/下载能力，要么需要额外资源与构建流程。
