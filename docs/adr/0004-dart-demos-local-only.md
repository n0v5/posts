# Dart 教程不在页面内执行真实 Dart 代码

本页是静态、单文件、可离线的专题页，Dart 又无法像 HTML/JS 一样由浏览器直接运行。为了让页面保持零外部依赖、可离线、无隐私与第三方稳定性风险，决定不内嵌 DartPad iframe、不接编译服务、不把示例预编译为 JS；交互演示只用本地 JS 模拟概念（类型推断、空安全流、集合管道、模式匹配、事件循环、Isolate 消息传递），代码块提供复制与指向 `dartpad.dev` 的空白外链。备选方案是内嵌 DartPad 或构建期编译 Dart 到 JS，但前者破坏离线与零外部请求，后者引入构建依赖且演示范围仍受限于可编译片段。
