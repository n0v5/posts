# 形式的边界采用 MDX 连载而非单页专题

《形式的边界：元数学、集合论与逻辑》需要 31 篇可独立链接、可增量发布、带系列导航、前置依赖与单篇源码查看的章节。现有单页专题模式适合一本书式的长页面，但不适合按篇索引、跨篇依赖与单篇更新。因此决定使用 Astro 内容集合中的 MDX 连载，扩展 frontmatter 的 `series`、`seriesPart`、`seriesOrder` 字段，并提供 `/series/forms-boundary/` 索引与系列内导航；不采用单文件 HTML 或单页 Astro 布局。备选方案是单文件专题页与分部长文：前者难以维护 31 篇的链接与增量发布，后者单页过长、导航与移动端阅读成本高。
