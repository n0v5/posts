## 前置概念

- 第 14–15 篇：序数、基数、基数算术、选择公理。
- 可定义性、绝对性、内模型。

## 本篇新术语

- **连续统假设（CH）**：$2^{\aleph_0}=\aleph_1$。
- **广义连续统假设（GCH）**：对每个无限基数 $\kappa$，$2^\kappa=\kappa^+$。
- **构造性宇宙 $L$**：从空集开始，每层只加入可定义子集的内模型。
- **绝对性**：一个概念在传递模型与 universe 中含义一致。
- **凝聚性**：$L$ 的层级在初等子结构上自我反映的性质。

## 问题：连续统到底有多大？

Cantor 证明 $2^{\aleph_0}>\aleph_0$。自然的问题是：它是否就是下一个基数 $\aleph_1$？这就是连续统假设。

CH 不是普通的技术问题。它问的是实数集的“最小可能大小”是否已经实现；它与测度、基数算术、力迫公理和大基数都有联系。Gödel 的 $L$ 给出了一个方向：在一个可定义的、最小的内模型中，CH 为真。因此 CH 不能被 ZFC 反驳（若 ZFC 一致）。

<Definition number="16.1" title="CH 与 GCH">
- **CH**：$2^{\aleph_0}=\aleph_1$。
- **GCH**：对每个无限基数 $\kappa$，$2^\kappa=\kappa^+$。
</Definition>

## 构造性宇宙 L

<Definition number="16.2" title="Gödel 的 L">
用超限递归定义：

- $L_0=\emptyset$；
- $L_{\alpha+1}=\mathrm{Def}(L_\alpha)$，即 $L_\alpha$ 中所有用一阶公式与 $L_\alpha$ 中参数可定义的子集；
- 对极限序数 $\lambda$，$L_\lambda=\bigcup_{\alpha<\lambda}L_\alpha$；
- $L=\bigcup_{\alpha\in\mathrm{Ord}}L_\alpha$。
</Definition>

$L$ 与 $V$ 的差别在于：$V_{\alpha+1}$ 取**所有**子集，而 $L_{\alpha+1}$ 只取**可定义**的子集。因此 $L\subseteq V$，且 $L$ 是一个内模型：它与 $V$ 有相同的序数，但可能缺少某些集合。

<Metaphor title="可定义的宇宙" breaking="L 不是‘我们语言中可定义的集合’的简单总汇；‘可定义’是相对于每层 $L_\alpha$ 与一阶语言而言的，而且 L 是内部构造，不是外部描述。">
把 L 想成一座只用“可定义图纸”建造的城市：每一层只接纳能用公式从上一层筛出的建筑。这个比喻能说明 L 的“最小性”，但不能说明它的技术定义：可定义性是模型内部的，不是我们随手写一个中文描述。
</Metaphor>

<Theorem number="16.1" title="L 满足 ZFC + AC + GCH">
$L$ 是 ZFC 的内模型，并且在 $L$ 中 AC 与 GCH 成立。
</Theorem>

<Proof sketch>
**ZFC**：逐条验证公理在 $L$ 中成立。分离与替换用“可定义性在 $L$ 中绝对”以及 $L$ 对序数的封闭性；幂集在 $L$ 中不是真正的幂集，而是“$L$ 中的可定义子集集”，需要证明它满足幂集公理的内模型版本。

**AC**：在 $L$ 中，每个集合都在某个 $L_\alpha$ 中，而 $L_\alpha$ 可以用序数递归良序化；把“最小定义阶段 + 最小公式编号 + 参数顺序”组合起来，得到 $L$ 的一个全局良序。全局良序推出 AC。

**GCH**：核心是凝聚性（condensation）：若 $M\prec L_\kappa$ 且 $M$ 传递，则 $M=L_\lambda$ 对某个 $\lambda$。用凝聚性可以证明，$L$ 中每个子集都出现在足够早的层级，从而 $2^\kappa\le\kappa^+$；Cantor 定理给出反向不等式。细节属于集合论的技术核心，此处只给骨架。
</Proof>

<Theorem number="16.2" title="CH 的相对一致性">
若 ZFC 一致，则 ZFC + AC + GCH（因而 ZFC + CH）一致。
</Theorem>

<Proof>
由定理 16.1，若 $V$ 是 ZFC 的模型，则 $L^V$ 是 ZFC + AC + GCH 的模型。因此若 ZFC 有模型，ZFC + AC + GCH 也有模型。相对一致性是模型存在性的传递，不是“在 ZFC 中证明了 CH”。
</Proof>

这个结论只给出一个方向：CH 不能被 ZFC 反驳。它没有说 CH 为真，也没有说 CH 可证。要证明另一个方向——CH 不能被 ZFC 证明——需要力迫法，下一篇开始。

## 绝对性与内模型

绝对性是指：某些概念在传递模型与 universe 中定义一致。例如“$x$ 是空集”“$x$ 是序数”“$x$ 是有序对”是绝对的；“$x$ 是幂集”不是绝对的，因为内模型可能缺少子集。

$L$ 的构造大量依赖绝对性：我们要在 $L$ 内部重新解释“公式”“可定义”“满足”，并证明这些解释与外部一致。若没有绝对性，$L$ 可能只是一个人为的语法对象，无法证明它满足 ZFC。

## 替代方案与冗余分析

- **$V=L$**：假设所有集合都是可构造的。它推出 GCH，但与大基数不相容（可测基数会推出 $0^\sharp$，从而 $V\ne L$）。
- **力迫扩张**：从 $L$ 或任意模型出发，加入新子集，构造 CH 失败的模型；它证明 CH 独立。
- **内模型方法**：$L$ 是最简单的内模型；更复杂的内模型（如 $L[\mu]$）用于大基数。
- **把 L 当成“所有可定义集合”**：不准确；$L$ 是分层可定义，且“可定义”相对于模型内部语言。

</Exercise>

<Exercise number="16.2" title="AC 在 L 中">

</Exercise>

</Exercise>

<Exercise number="16.4" title="开放题">

</Exercise>
